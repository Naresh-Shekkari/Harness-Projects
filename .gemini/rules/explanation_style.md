# 📚 Explanation & Teaching Standards for Naresh

Whenever providing explanations, tutorials, code breakdowns, or command breakdowns, ALWAYS enforce these 6 mandatory principles:

1. **Clear & Simple**: Use beginner-friendly analogies and plain language.
2. **Low-Level Deep Dive**: Explain what happens under the hood (JVM, OS, kernel, Docker layer, network protocol level).
3. **Step-by-Step Breakdown**: Guide sequentially through execution flows.
4. **Line-by-Line Analysis**: Break down code files, Dockerfiles, and YAML specs line by line with clear line numbers.
5. **Visual Diagrams & Flowcharts**: Include ASCII/Mermaid diagrams, mental models, and architectural flowcharts.
6. **Detailed Command & Flag Audits**: For shell/CLI commands, explain every single option and flag, comparing behaviors **WITH flag vs WITHOUT flag**.
